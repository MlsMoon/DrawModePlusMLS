# draw-mode-plus-mls-skill

Routing skill for [DrawModePlusMLS](https://github.com/MlsMoon/DrawModePlusMLS). This folder is **not** its own Git repository.

A Plastic SCM pull of a game project copies these files without `.git`. Edit and push the plugin instead:

- Git: https://github.com/MlsMoon/DrawModePlusMLS
- Install / update: [Moon Game Dev Tool Manager](https://github.com/MlsMoon/moon-game-dev-tool-manager)

Then sync this routing copy from the plugin (from source / to source).
